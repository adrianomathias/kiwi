# Site Institucional — Hortifruti

Site desenvolvido como projeto demonstrativo pela **B2B tech** para um hortifruti, com foco em apresentar produtos, destacar a qualidade dos alimentos e facilitar a comunicação com clientes.

## Sobre o projeto

A proposta do site é criar uma presença digital para um hortifruti, apresentando seu catálogo de produtos de forma simples, organizada e visualmente atrativa.

O projeto pode ser utilizado como base para estabelecimentos que desejam divulgar seus produtos, receber pedidos e fortalecer sua presença digital.

## Objetivos

- Apresentar produtos disponíveis;
- Organizar o catálogo de forma intuitiva;
- Destacar frutas, verduras e legumes;
- Facilitar o contato com clientes;
- Criar uma presença digital profissional;
- Demonstrar uma solução web desenvolvida pela B2B tech.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap

## B2B tech

A **B2B tech** atua no desenvolvimento de soluções digitais e sites para empresas e negócios.

Este projeto faz parte do portfólio demonstrativo da B2B tech.
